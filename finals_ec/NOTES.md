# Notes

## User preferences
- Oral exam format: 15-min answer + 2 follow-up questions per topic
- All learner-facing content in Czech
- Minimal material: concise blueprints, not textbooks
- Active recall is the primary learning activity
- Mastery = can explain without looking; reading does not count
- Token/cost optimization: high information density, no repetition

## Exam format
- 20 topics total; receives 2 at the exam
- Each topic: ~15 min answer + up to 2 follow-up questions
- Oral examination (BSP Ekonomika a management, SSEKP)

## Learning system architecture
- Main dashboard: index.html → 20 topic cards
- Each topic: lessons/XX-slug.html
  - Tab 1: Blueprint (structure + must-say + terms + examples + mistakes + follow-ups)
  - Tab 2: Recall Mode (question → triggers → reveal)
  - Tab 3: Paměťová mapa (10–20 keywords)
- Exam simulation: built into index.html
